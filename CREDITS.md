# Credits

## Background music

The soft background sound in Drishti is a tanpura-style drone synthesized in the browser with the Web Audio API (`musicBuild` in `web/index.html`). It is original code written for this app. The partials sit in the mid range so a phone speaker can play them; there is still no recording.

No recording, sample, or composition by anyone else is included. There is no audio file to download, and there is no third-party music license. The sound is free to ship in the Google Play app.
