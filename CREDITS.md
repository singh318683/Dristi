# Credits

## Background music

The soft background sound in Drishti is a tanpura-style drone synthesized in the browser with the Web Audio API (`DrishtiMusic` in `web/index.html`). It is original code written for this app.

No recording, sample, or composition by anyone else is included. There is no audio file to download, and there is no third-party music license. The sound is free to ship in the Google Play app.
